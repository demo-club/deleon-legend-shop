# DELEON — Legend Club

Tienda de streetwear minimalista (deleonlegend.club) con productos impresos bajo demanda por Tapstitch.

**Web en vivo**: https://deleon-legend-shop.lovable.app

## Publicación

La tienda se publica desde Lovable (botón Publish). El dominio personalizado se conecta en
Project Settings → Domains. No usar GitHub Pages: la app necesita servidor y Pages solo sirve archivos estáticos.

## Desarrollo local

```sh
npm i
npm run dev
```
